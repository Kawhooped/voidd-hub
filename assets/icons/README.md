# VOID.LIFE icon library

Upload the original icon PNG files into this folder. Use descriptive lowercase filenames, for example `creativity.png`, `house.png`, `rocket.png`, `flower.png`, `graduation-cap.png`, `conversation.png`, `network.png`, `interface.png`, and `settings.png`.

Keep the original transparent PNG backgrounds. Avoid duplicate uploads; the same file name will be treated as a replacement by GitHub's upload workflow.
